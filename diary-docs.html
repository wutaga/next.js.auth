1 Обзор проекта

Дневник — веб-приложение для ведения личных записей с системой авторизации и управления профилем. Приложение позволяет пользователям регистрироваться, входить в систему, создавать, редактировать и удалять записи с возможностью отслеживания настроения.

Проект создан в образовательных целях и демонстрирует полный стек современной веб-разработки: от базы данных до клиентского интерфейса.

6 Система авторизации

Поток авторизации

1Пользователь вводит email и пароль на странице /login
2NextAuth вызывает функцию authorize() в auth.ts
3Prisma ищет пользователя в базе данных по email
4bcrypt.compare() сравнивает введённый пароль с хешем в базе
5При успехе — создаётся JWT токен и сохраняется в cookie браузера
6Токен автоматически прикладывается к каждому запросу

Защита страниц (proxy.ts)

Файл proxy.ts перехватывает каждый запрос до того как он дойдёт до страницы:

  • Незалогиненные → попытка зайти на /dashboard, /profile, /diary/* → редирект на /login
  • Залогиненные → попытка зайти на /login или /register → редирект на /dashboard

Безопасность

  • Пароли хранятся в виде bcrypt-хеша с cost factor 12
  • JWT токен подписан секретным ключом AUTH_SECRET из .env
  • Каждый API роут проверяет сессию перед выполнением операций
  • Записи привязаны к userId — пользователь не может читать чужие записи
  • Секретные переменные окружения не попадают в клиентский код

8 Запуск проекта

Требования

  • Node.js 18+
  • PostgreSQL 16
  • npm

Установка

# Перейти в папку проекта
cd ~/nextjs

# Установить зависимости
npm install

# Настроить .env (DATABASE_URL и AUTH_SECRET)

# Применить миграции к базе данных
npx prisma migrate dev

# Запустить сервер разработки
npm run dev

Приложение будет доступно по адресу: http://localhost:3000

Визуальный интерфейс базы данных: http://localhost:5555 (после npx prisma studio)
